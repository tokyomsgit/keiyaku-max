# 社内Coworkプラグイン

東京マンションサービスの業務用Coworkプラグインを配布するリポジトリです。

ローカルの案件確認・差分採用・Excel生成画面は、[Web版の起動手順](WEB_README.md)を参照してください。

## 収録プラグイン

| プラグイン | 内容 |
|---|---|
| tohon-keiyakusho | 登記簿謄本を読み取り、契約書ひな型の「基本入力」シートへ自動で転記する |

## 使う人向け: 導入手順

一度だけ登録すれば、以後の更新は自動で届きます。

1. Claude Desktopを開き、上部の **Cowork** タブをクリック
2. 左サイドバーの **カスタマイズ** を開く
3. **プラグイン** タブを選ぶ
4. **マーケットプレイスを追加** を選び、このリポジトリのURLを入力する
5. 一覧に出てきた `tohon-keiyakusho` をインストールする

更新が出たら、プラグイン画面のマーケットプレイスにある **更新** を押してください。

### 併せて必要なもの

**名前定義版の契約書ひな型** が必要です。基本入力の入力欄に「謄本_」「借地_」で始まる名前が
定義されているもので、古いひな型を渡すとスクリプトが止まります。
ファイルサーバーの原本を使ってください。

## 直す人向け

### 謄本の読み取り精度を上げたいとき

`plugins/tohon-keiyakusho/skills/tohon-nyuryoku/references/reading-rules.md` を編集します。
謄本の罠や物件類型ごとの読み方はすべてここに書いてあります。

### ひな型の入力欄を新設・移動したとき

Excelの「数式」→「名前の管理」で名前の参照先を直します。
行の挿入・削除だけなら名前定義が追従するので、何もしなくて構いません。

新しい入力欄を追加した場合のみ、Excelで名前を定義したうえで
`plugins/tohon-keiyakusho/skills/tohon-nyuryoku/scripts/mapping.json` に項目を足します。

### 変更を配布するとき

1. 変更をコミットしてこのリポジトリにpushする
2. `plugins/tohon-keiyakusho/.claude-plugin/plugin.json` の `version` を上げる
3. 社員に「プラグイン画面で更新を押して」と伝える

`fill_tohon.py` は原則として触りません。

## 購入時重説と管理規約

購入時重説の補正は原本確認記録をSHA256キャッシュの`reviewed_fields.json`へ保存します。元の解析結果は変更しません。管理規約も同じ方式で条文・ページ・確認日時を保持し、未確定の改正内容は要確認に残します。

購入時の売買代金・手付金・引渡日は`purchase_mapping.json`と`purchase_template_names.json`で名前定義へ対応付けます（上記scripts内）。未取得の入力欄は空欄にします。管理費・修繕積立金・管理規約は現在の「基本入力」に適切な専用欄がないため、保存・画面確認のみです。購入時点の取引条件は今回の取引条件とは異なるため、生成前に確認してください。

## 見た目を変更する場合

- 色・文字サイズ・余白・角丸・枠線：`web/styles/theme.css`
- 画面幅・配置・レスポンシブ：`web/styles/layout.css`
- ボタン・表・状態表示・根拠・アップロード：`web/styles/components.css`
- リセット・本文・見出し・表の基本：`web/styles/base.css`

`web/style.css`は読込入口です。HTML/JavaScriptへ見た目を直書きせず、クラスとthemeの変数を使用します。公開デモのビルドでは同じ4ファイルを1つのCSSにまとめます。

### PDFの実読取とデモ
通常起動は `.env` の `DEMO_MODE=false` とサーバー側の `OPENAI_API_KEY` を使用します。既存キャッシュがあるPDFは再解析しません。設定変更後は起動中のサーバーを終了して `run_local.bat` で再起動してください。キャッシュだけで確認する場合は `run_demo.bat` を使用します（通常版と混同しないようポート8766で起動）。

### AI料金・ローカル優先処理
単価と概算係数は `config/ai_pricing.json` で変更できます。GPT-4.1の単価出典は同ファイルの公式URLです。円換算 `usd_to_jpy` と画像1ページの仮定額 `image_page_estimate_usd` は未設定で、AI料金は「概算不能」と表示します。設定値による表示は確定請求額ではありません。料金確認のためにAI APIは呼びません。
`AI_COST_LIMIT_JPY` が設定された場合、上限超過または見積不能ではAIを開始しません。未設定なら上限なしです。確認トークンは30分有効で資料・単価と照合します。テキストのローカル候補は原本確認が必要です。画像のみの管理規約は条文を限定できないため全文送信せず停止します。
