# 謄本から契約書ひな型への自動転記

登記簿謄本(全部事項証明書)のPDFを読み取り、契約書ひな型の「基本入力」シートへ転記します。
基本入力が埋まれば、重説・売契・媒介・約定まで既存の数式で自動展開されます。

## 使い方

謄本PDFを渡して「謄本入れといて」と言うだけです。フォルダを指定すれば複数物件をまとめて処理します。

## 埋まる項目

一棟の建物の所在・構造・延床面積、専有部分の家屋番号・種類・構造・階部分・床面積・建築時期、
所有者の氏名と住所、土地の所在・地番・地目・地積・権利の種類・持分、敷地権の有無。

## 対象外

戸建ては対象外です(ひな型が区分所有前提のため)。謄本を渡すとその旨を伝えて止まります。

## 埋まらない項目

買主、物件名、住居表示、間取り、壁芯面積、契約日、価格、融資関係、業者情報。
**住居表示だけは謄本より先に入力してください。** 所在と家屋番号がここから組み立てられます。

## ひな型について

**名前定義版のひな型が必要です。** 基本入力の入力欄に「謄本_」「借地_」で始まる名前が
定義されているもので、古いひな型を渡すとスクリプトが止まります。

ひな型をExcelで改訂(行の挿入・削除など)しても、名前定義が追従するので設定を直す必要はありません。
入力欄そのものを新設・移動したときだけ、Excelの「数式」→「名前の管理」で参照先を直します。

## 注意

自動転記の結果をそのまま契約書として使わないでください。必ず謄本と並べて目視確認します。
