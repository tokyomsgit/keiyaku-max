# 謄本読み取りルール

登記簿謄本(全部事項証明書)から中間JSONを作るときの規則。
実物件で実際に踏んだ落とし穴を元にしている。

## 絶対に守ること

**下線のある記載は抹消事項。絶対に採用しない。** 必ず最新の記載を使う。
土地の謄本では、分筆・合筆のたびに古い地積が下線付きで残る。例:

```
142:14 → 64:68 → 427:49 → 601:28   ← 有効なのは最後の 601.28 だけ
```

**面積欄の全角コロン「：」は小数点。** `４４２：５４` は 442.54。
**全角数字は半角に直す。**

**氏名・法人名は1字ずつ全角スペースで印字される。スペースを全て詰める。**

```
Ａ　Ｂ　Ｃ　Ｄ　株　式　会　社  →  ABCD株式会社
山　田　太　郎                  →  山田太郎
```

**謄本に無い項目は推測で埋めない。** 空文字か null にする。

## 所有者(権利部 甲区)

**順位番号が最も大きい所有権移転の所有者を取る。** 古い順位の所有者ではない。

売買で移転していれば、前の所有者はもう関係ない。順位1番に個人、順位2番に買取再販業者、
という形はよくある。この場合の正解は順位2番。

- 「付記◯号 登記名義人住所変更」があれば、そちらの住所を採用する
**表題部の「所有者」欄を拾わない。** 表題部の末尾に所有者が書かれていることがあるが、
これは所有権保存前の原始取得者(分譲業者など)。甲区に所有権保存または移転があれば、必ず甲区が正しい。

表題部に分譲業者の法人名が、甲区1番の所有権保存に個人名が入っている形が典型。
この場合の正解は甲区1番の個人名。

- 複数名なら氏名を「、」で区切って全員並べ、`_要確認` にも書く(ひな型は1名分の枠しかない)
- 法人なら `_要確認` に「売主が法人。基本入力の売主区分(宅建業者/個人・一般法人)を確認」と書く

## 土地

**建物謄本の「表題部(敷地権の目的である土地の表示)」から取る。**
土地謄本には抹消済みの古い地積が並ぶため、主データにしない(取得済みなら突合用に使う)。

- 1筆目の所在・地番はひな型が住居表示から自動生成するので空文字でよい
- 2筆目以降は所在・地番とも入れる
- 敷地権の割合は「表題部(敷地権の表示)」から取る
- 土地の符号が「1・2」のように複数を指す場合、**全ての筆に同じ割合**を入れる
- 「100000分の1570」なら分母が100000、分子が1570。逆にしない

## 各階床面積

延床面積は謄本に記載が無いため、一棟の建物の**各階の床面積を全て**拾う。スクリプトが合計する。

- **地下階を必ず含める。** 構造欄の「地下◯階付」と階数が合っているか確認する
- 階の名前は謄本の表記どおり(`地下1階`、`1階`、`11階`)

## 一棟の建物の所在

複数の地番にまたがることがある。

```
◯◯区△△一丁目　５３５番地２　□□区××町２５８番地６
```

この場合、`所在_番`=535、`所在_枝番`=2、`所在_追加`=`　□□区××町258番地6`
(先頭に全角スペース)。市区町村＋町丁目は `所在_市区町村町名` に入れる。

## 建物の名称

謄本に記載が無い場合のみ `建物の名称_補足` に `(登記記録上記載なし)` と入れる。
記載があれば空文字(ひな型は物件名を別に持っている)。

## 権利部 乙区

抹消されていない抵当権・根抵当権が残っていれば、`_要確認` に債権者名・設定日・債権額を書く。
決済時の抹消段取りに関わるため、必ず報告する。

## 作ったJSONの自己チェック

書き込む前に確認する。

1. 所有者は甲区の一番下の順位番号から取ったか
2. 地下階を拾えているか。構造の「地下◯階付◯階建」と階数が一致するか
3. 敷地権の割合の分母と分子が逆になっていないか
4. 下線付きの古い地積を拾っていないか
5. 氏名・法人名のスペースを詰めたか

## 物件の類型を最初に見分ける

謄本の表題部の見出しで判断する。類型ごとに読み方が変わる。

| 表題部の見出し | 類型 | 対応 |
|---|---|---|
| 一棟の建物の表示 ＋ 敷地権の表示(所有権) | 通常の区分所有 | 標準どおり |
| 一棟の建物の表示 ＋ 敷地権の表示(地上権/賃借権) | 借地権付きマンション | 借地の項目も埋める(下記) |
| 一棟の建物の表示のみ、敷地権の表示が無い | 非敷地権マンション | 土地は別謄本から(下記) |
| 主である建物の表示 | 戸建て | **対象外。** 転記せず、その旨を伝えて止まる |

## 借地権付きマンション

敷地権の種類が「所有権」ではなく**地上権**または**賃借権**になっている。

- 土地の「権利の種類」に地上権(または賃借権)と入れる
- 借地の条件は**土地謄本の乙区**から読む。地上権設定の「存続期間」「地代」を拾う
- 貸主(地主)は土地謄本の**甲区**の所有者。建物謄本の所有者ではない
- 借地権の新旧は設定日で決まる。**平成4年7月31日以前の設定なら旧法借地権**
- 地上権の場合、譲渡承諾は不要(賃借権の場合は必要)。`_要確認` にどちらかを明記する
- **地代は謄本では「3.3㎡当り1月◯円」のような単価表記が多い。** 月額の総額は謄本だけでは出せないので
  `地代_月額` は null にして `_要確認` に書く。借地説明書があればそちらを読む

借地の中間JSONは `借地` オブジェクトを追加する。無い物件では省略する。

```json
"借地": {
  "対象面積": 873.97,
  "面積の根拠": "登記簿",
  "地代_月額": null,
  "建物区分": "堅固建物",
  "貸主住所": "", "貸主氏名": "",
  "法区分": "旧法",
  "新法の種類": null,
  "譲渡承諾特約": false,
  "期間_開始": { "元号": "昭和", "年": 47, "月": 1, "日": 31 },
  "期間_終了": { "元号": "令和", "年": 14, "月": 1, "日": 30 },
  "期間_年数": 60
}
```

`建物区分` は堅固建物か非堅固建物。鉄筋・鉄骨造は堅固、木造等は非堅固。
`法区分` は設定日が平成4年7月31日以前なら旧法、以降なら新法。新法のときだけ
`新法の種類` に普通借地権か定期借地権を入れる。

実例(物件B): 昭和47年1月31日設定の地上権、存続期間60年、
地代3.3㎡当り月400円、敷地権の割合612696分の4178。旧法・地上権と判定する。

## 非敷地権マンション

敷地権の表示が無く、土地は区分所有者の共有になっている。

- 建物謄本には土地の情報が無い。**土地謄本が必須**
- 土地の持分は土地謄本の**甲区から所有者名で探す**。「◯◯持分全部移転」の登記を追う
- 甲区が数百件に及ぶことがある(実例で41ページ・順位190番)。ページ全体を機械的に読まず、
  建物謄本で特定した所有者名を手がかりに検索する
- 土地謄本が渡されていなければ、**持分は推測せず空欄にして `_要確認` に書く**
- ひな型の敷地権チェックは「無」にする(`"敷地権": false`)

実例(物件C): 土地謄本の甲区190番「◯◯持分全部移転」に建物の所有者名が現れ、
持分1万分の204と記載されていた。前所有者の氏名が登記の目的に出るのが手がかりになる。

## 家屋番号の枝番と部屋番号は一致しない

家屋番号の末尾と建物の名称(部屋番号)が違うことが多い。両方を別々に読む。

| 物件 | 家屋番号 | 建物の名称 |
|---|---|---|
| 物件A | 535番2の704 | 704(一致) |
| 物件C | 314番4の5 | 204(不一致) |
| 物件B | 69番9の110 | 1010(不一致) |

## スキャンPDFについて

登記情報提供サービスのPDFにはテキスト層があるが、紙をスキャンしたPDFには無い。
どちらも画像として直接読めば問題なく読み取れる。OCRソフトは不要。
「COPY」の透かしが重なっていても読める。

## まだ検証できていない類型

- 共有名義(ひな型の所有者欄は1名分しかない)
- 定期借地権
- 底地(借地権が設定された土地そのものの売買)

遭遇したら `_要確認` に「未検証の類型」と明記し、ユーザーに確認する。
